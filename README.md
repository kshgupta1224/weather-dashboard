# Weather Dashboard

A simple client-side weather dashboard that fetches current weather and 5-day forecast for a city using the OpenWeatherMap API.

Features
- Search for a city and view current weather
- 5-day forecast overview
- Responsive, minimal UI

Usage
1. Get an OpenWeatherMap API key: https://openweathermap.org/api
2. Open index.html in a browser or serve via a static file server.
3. In script.js replace `const API_KEY = 'YOUR_API_KEY_HERE'` with your API key, or set it via a build step.
